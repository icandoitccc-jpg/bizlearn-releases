# BizLearn

我自己制作的商业知识学习工具，免费分享给感兴趣的人。— Chen’s Tricks

中文为主，附英文概念和定义。通过情境判断、概念学习、换场景练习和自己的表达来学习，包含 **90 节商业课、3 节管理课、18 个小测、100 张术语卡**，以及复习、知识库和本地进度。

## Windows 安装

1. 下载 ZIP，右键“全部解压缩”。
2. 阅读“先读我.txt”，运行 BizLearn-Setup-1.0.1.exe，按向导安装。
3. 从桌面或开始菜单打开 BizLearn。

安装包未签名，可能出现“未知发布者”或 SmartScreen。核对作者来源、SHA256 并扫描后，如确认信任来源且系统提供选项，可点击“更多信息 → 仍要运行”。若报告具体恶意软件、哈希不符或公司策略禁止，请停止并反馈，不关闭安全防护。

## Mac 安装和首次打开

1. 下载对应芯片的 ZIP，双击解压。
2. 把 BizLearn.app 拖入“应用程序”，再打开。
3. 如提示 Apple 无法验证此应用，点击“完成 / Done”。它只关闭提示，不会继续打开。
4. 确认来源后，打开“系统设置 → 隐私与安全性”，向下找到 BizLearn 被阻止的提示，点击“仍要打开 / Open Anyway”，按提示确认。
5. 没有该选项时，再次尝试打开应用，然后返回设置查看。

Mac 包没有 Apple Developer ID 签名或 Apple 公证，Apple 芯片版的本地临时签名不等于身份认证。其他报错请保留截图反馈。应用声明最低 macOS 10.15，并非所有版本均已实测。

## 免费使用与数据

- 核心课程和练习离线可用，无需注册或购买 API。
- “系统预检”仅检查表达结构，不代表回答一定正确。
- “复制给 AI 点评”需要自行粘贴到外部 AI，其费用和隐私规则以所选服务为准。
- 进度在本机。设置 → 导出进度到剪贴板后，粘贴到文本文件保存。更新前先备份并退出旧版，安装到原目录，不先卸载。
- 同步码会把进度及表达上传到公共第三方 ntfy.sh，知道或猜中码的人可能读取。建议优先本地备份，不填写个人隐私、客户资料或公司机密。
